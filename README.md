# World AI Art Museum (WAAM)

Non-commercial research platform for verified AI-generated art.

## Status
- Launch v1: static catalog + CLI verification pipeline (in progress)
- Discovery Engine: planned

## Core Principle
Discovered ≠ Verified ≠ Published.
No artwork enters the public collection without confirmed provenance and rights basis.
